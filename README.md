# Dog Breed Classification using Deep Learning

This project is an end-to-end Computer Vision application that classifies dog breeds from images using Deep Learning. The model is built with TensorFlow and Keras and leverages transfer learning to achieve high classification performance on a large-scale image dataset.

## Project Highlights

* Built an end-to-end image classification pipeline.
* Applied image preprocessing and augmentation techniques.
* Utilized transfer learning with a pre-trained CNN architecture.
* Trained and evaluated the model on thousands of labeled dog images.
* Performed inference on unseen images for breed prediction.
* Visualized model predictions and evaluated performance.
